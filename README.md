# وِرد | Wird

مكتبة الأستاذة فتحية إبراهيم الشهري. موقع عربي ثابت للقراءة والتحميل مجانًا، دون حسابات أو إعلانات أو تتبع.

## الصفحات
- `index.html`: الرئيسية والكتاب الأول.
- `library.html`: جميع الكتب والبحث والتصنيف.
- `book.html?id=rawdat-al-uns`: تفاصيل كتاب.
- `reader.html?id=rawdat-al-uns`: قارئ مستقل.
- `about.html`: عن المكتبة.

## إضافة كتاب
1. ضع PDF الأصلي في `books/` والغلاف في `covers/` دون قص.
2. أضف عنصرًا في `catalog.js` بمعرّف فريد، والعنوان والمؤلف والنبذة والتصنيف (`personal` أو `heritage`) وعدد الصفحات واللغة والحجم ومسارات الملف والغلاف وبيان الإتاحة.
3. يظهر الكتاب تلقائيًا في المكتبة، ويعمل رابط التفاصيل والقارئ باستخدام `?id=معرف-الكتاب`.
4. الرئيسية تحتفظ بالكتاب الافتتاحي المختار تحريريًا. غيّرها يدويًا عند اختيار كتاب افتتاحي جديد.
5. لا تنشر الكتب القديمة إلا بعد التحقق من حق إعادة نشرها وتوثيق مصدرها في بيان الإتاحة.

## القارئ
PDF.js مستضاف محليًا (Apache 2.0، الترخيص في assets/vendor). عرض صفحة واحدة أو صفحتين على الشاشات الواسعة، تكبير، انتقال لصفحة، اختصارات الأسهم، إيماءة أفقية على الجوال، حفظ محلي لموضع القراءة والمظهر وخيارات العرض. الرسم الحالي والصفحة المجاورة فقط يُجهزان عند الحاجة. الملف نفسه يُطلب عند فتح القارئ فقط، وليس مع الرئيسية.

التقليب حركة ثلاثية الأبعاد خفيفة اختيارية، وليس محاكاة كاملة لطي الورق. ملء الشاشة يعتمد على دعم المتصفح وسياساته. النصوص المرئية تُرسم من صفحات PDF الأصلية؛ استخراج النص لقارئات الشاشة يتأثر ببنية PDF الأصلي. لا ندّعي أن الملف الأصلي يوفر نصًا عربيًا صالحًا للاستخراج بالكامل.

## التطوير والنشر
لا مدير حزم ولا بناء مطلوب للنشر. GitHub Pages ينشر جذر الفرع main. المسارات نسبية ومتوافقة مع `/wird-library/`.
محليًا: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
الخطوط محلية: Amiri وNoto Sans Arabic، بيانات الترخيص في `assets/fonts/LICENSES.txt`.
