# وِرد | Wird Library

مكتبة عربية شخصية بسيطة لنشر الكتابات الأصلية والكتب القديمة المتاحة قانونيًا مجانًا، مع القراءة المباشرة والتحميل دون تسجيل دخول.

## أهداف الموقع
- الأولوية للقراءة وسهولة الاستخدام، خصوصًا على الجوال.
- «كتاباتي»: الأعمال والنصوص الشخصية التي يختار صاحب الموقع نشرها.
- «كتب قديمة»: أعمال ثبت أنها في الملكية العامة أو لها تصريح/ترخيص واضح بإعادة النشر.
- القراءة المجانية لا تعني أن العمل مفتوح المصدر أو خاليًا من حقوق النشر.

## نشر الموقع
الموقع ثابت. في GitHub اختر: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## إضافة كتاب
1. تأكد من حق إعادة نشر الكتاب، واحتفظ ببيانات المصدر والترخيص.
2. ارفع ملف PDF إلى مجلد `books/` وصورة غلاف اختيارية إلى `covers/`.
3. في `app.js` أضف عنصرًا إلى مصفوفة `books`:
```js
{
  title: "عنوان الكتاب",
  author: "اسم المؤلف",
  description: "نبذة قصيرة",
  category: "personal", // أو heritage
  file: "books/example.pdf",
  cover: "covers/example.webp" // اختياري
}
```
4. احفظ الملف وستظهر بطاقة الكتاب تلقائيًا بعد تحديث النشر.

## القارئ
النسخة الأولى تستخدم عارض PDF المدمج بالمتصفح مع بديل لفتح الكتاب في نافذة مستقلة، ويمكن لاحقًا تقديم قارئ مخصص لتقليب الصفحات.

## الكتاب المرفق
«روضة الأنس في أدعية النفس» (27 صفحة)، إعداد وكتابة فتحية إبراهيم الشهري، لم يُنشر في المستودع لعدم التحقق بعد من إذن نشره العام.

لا تسجيل دخول ولا إعلانات أو تحليلات تتبع في هذه النسخة.
